# NewDawn - Township Informal Job Opportunity App

## Live API
https://newdawn-api-production.up.railway.app/

## Features Implemented
- User registration with bcrypt password encryption
- User login with JWT authentication
- Job posting and browsing
- Offer submission and acceptance
- Settings (language, notifications, password change)
- Offline-ready architecture (Room + WorkManager planned)

## Tech Stack
- Android: Kotlin, Jetpack Compose, Retrofit, DataStore
- Backend: Node.js + Express + PostgreSQL (Neon)
- Hosting: Railway
- Authentication: JWT + bcrypt
